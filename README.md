# Smart Solity Doorlock — Home Assistant 커스텀 통합

솔리티(SOLITY) 스마트 도어락을 **SmartThings 없이** 솔리티 클라우드 API로 직접 연동하는 Home Assistant 커스텀 통합구성요소입니다.

- 🔓 **잠금 / 해제(열기)** — `lock` 엔티티 (오토락 물리 특성에 맞춘 안정적인 잠김 상태 유지)
- 📡 **블루투스 프록시(Bluetooth Proxy) 로컬 제어** — ESPHome 블루투스 프록시를 통해 클라우드 거치지 않고 0초대 로컬 직결 제어 지원
- 🔀 **제어 방식 선택 (클라우드 / 블루투스 / 하이브리드)** — 블루투스 우선 시도 후 실패 시 클라우드로 자동 폴백하는 안심 하이브리드 모드 지원
- 👤 **얼굴키(1~7번) 실명 자동 동기화** — 솔리티 클라우드 서버에서 등록된 얼굴인식 키의 사용자 이름을 자동으로 수신하여 출입 알림에 실명 표시
- 🔋 **배터리 잔량** — `sensor` (재시작 및 통신 지연 시에도 상태 복원 유지)
- 🚪 **실내 개폐(안에서 열고 나감) 감지** — 안에서 레버/버튼을 누르고 나간 경우 "실내 개폐" 자동 구분 (`direction: inside`)
- 🕑 **초고속 이벤트 감지** — 도어락을 깨우지 않는 클라우드 로그 조회로 배터리 소모 없이 수초 내 출입 감지
- ⚙️ **편리한 UI 설정** — 솔리티 계정(이메일/비밀번호) 입력만으로 도어락 자동 검색 및 등록
- 🔁 **토큰 자동 갱신** — 30일 JWT 토큰 자동 관리 (만료 시 백그라운드 재로그인)
- 📟 **폰 앱과 독립 세션** — 전용 세션 토큰(`phoneToken: ha-solity`)을 사용하여 기존 스마트폰 솔리티 앱과 세션 충돌 없음

## 📦 설치

### HACS (커스텀 저장소)
1. Home Assistant 접속 ➔ **HACS** ➔ 우측 상단 점 3개(⋮) ➔ **Custom repositories(커스텀 저장소)** 선택
2. 저장소 URL에 아래 주소 입력, 카테고리 **Integration(통합구성요소)** 선택 후 추가:
   ```
   https://github.com/justicepng/Smart-Solity-Doorlock
   ```
3. HACS 목록에서 "Smart Solity Doorlock" 검색 ➔ **설치 / 다운로드** ➔ **Home Assistant 다시 시작**

### 수동 설치
저장소의 `custom_components/solity/` 폴더를 Home Assistant의 `/config/custom_components/` 디렉토리 아래로 복사한 후 Home Assistant를 다시 시작합니다.

---

## ⚙️ 설정

Home Assistant **설정** ➔ **기기 및 서비스** ➔ **통합구성요소 추가** ➔ **"Smart Solity"** 검색
➔ **스마트 솔리티 계정 이메일과 비밀번호** 입력 ➔ 도어락 자동 등록 완료.

- 도어락이 여러 개인 경우 선택 화면이 나타납니다.
- 통합구성요소의 **[구성 / 옵션]**에서 이벤트 로그 조회 주기, 상태 조회 주기, 자동 잠김 반영 지연 시간을 조절할 수 있습니다.

## 📊 제공 엔티티

| 엔티티 | 설명 | 주요 속성 |
| :--- | :--- | :--- |
| `lock.<도어락이름>` | 도어락 잠금/해제 및 실시간 개폐 상태 | `last_access_who`, `last_access_method`, `last_access_time`, `live_state` |
| `sensor.<도어락이름>_battery` | 배터리 잔량 (%) | `battery`, `device_class: battery` |
| `sensor.<도어락이름>_last_access` | 마지막 출입 정보 (누가 / 어떻게 / 언제) | `who`, `method`, `method_code`, `direction` (`inside`/`outside`), `datetime` |
| `event.<도어락이름>_door_event` | 실시간 출입 이벤트 발생기 (`open`/`close`) | `event_type`, `who`, `method`, `direction`, `synthetic` |

## 🔄 폴링 및 동작 원리

통합구성요소는 배터리 소모를 최소화하기 위해 **2단계 분리 폴링** 구조로 동작합니다:

| 폴링 종류 | 대상 API | 도어락 깨움(Sleep 해제) | 기본 주기 | 설명 |
| :--- | :--- | :---: | :---: | :--- |
| **이벤트 로그** | `retrieveLog` | ❌ 안 함 | **10초** (5~600초) | 클라우드에 저장된 출입 로그를 빠르게 읽어 배터리 부담 없이 즉시 출입 감지 |
| **상태 / 배터리** | `get_status` | ✅ 깨움 | **30분** (1~1440분) | 도어락을 직접 깨워 배터리 잔량을 동기화 |

### 🔐 열림/잠김 상태 반영 로직
- 솔리티 스마트 도어락은 문이 닫히면 자동으로 잠기지만, 솔리티 클라우드에는 **"열림(Open)" 로그만 기록**되고 "닫힘(Close)" 로그는 남지 않는 특성이 있습니다.
- 따라서 출입 로그로 열림이 감지되면 즉시 `unlocked(열림)`으로 전환하고, 설정된 **자동 잠김 반영 지연(기본 5초)** 뒤에 자동으로 **`locked(잠김)`** 상태로 복귀하여 안정적으로 유지됩니다.
- 도어락이 수면 모드이거나 일시적 네트워크 통신 지연이 발생하더라도 엔티티가 `unavailable`로 꺼지지 않고 직전 상태를 안전하게 유지합니다.

### 🚪 출입 수단 및 실내 개폐 감지
- **외부 출입**: 얼굴인식, 지문, 비밀번호, 카드키, 스마트폰 앱 등으로 문을 열었을 때 등록된 사용자 이름과 출입 수단이 한글로 표기됩니다 (`direction: outside`).
- **실내 개폐**: 안에서 수동 레버나 열림 버튼을 누르고 외출한 경우 자동으로 **"실내에서 문을 열었습니다"**로 감지하여 기록됩니다 (`who: 실내`, `method: 실내 개폐`, `direction: inside`).

## ⚠️ 유의사항

- **원격 열기/제어**: 도어락과 집안 공유기 사이에 **스마트솔리티 Wi-Fi 게이트웨이(GW-100 등)**가 연결되어 있어야 외부/인터넷을 통한 실시간 원격 열기(`open`)가 동작합니다. 게이트웨이가 없는 BLE 전용 환경에서는 출입 상태 감지 및 로그 확인 위주로 동작합니다.
- **출입 감지 반응 속도**: 도어락이 열린 후 도어락에서 솔리티 클라우드로 데이터를 보고하는 시간(수초) 후 Home Assistant에 반영됩니다.
- **계정 보안**: 계정 비밀번호는 원문 대신 솔리티 앱과 동일한 SHA-256 해시 형태로만 안전하게 보관됩니다.
